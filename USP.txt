1. FITUR UNGGULAN (USP)
================================================================================

  a. AI Generate Copy + Visual Prompt Sekaligus
     - Tidak seperti Canva (design-only) atau ChatGPT (teks doang tanpa
       struktur), Carofeed menghasilkan headline, body, DAN visualIdea
       untuk setiap slide dalam satu klik.
     - Output berupa JSON prompt siap pakai — tinggal paste ke image
       generator (ChatGPT, Midjourney, dll).

  b. 49 Style Presets dengan Preview Gambar Asli
     - 10 kategori visual (Modern, Illustration, 3D, Artistic, Classic,
       Tropical, Urban, Luxury, Playful, Minimal).
     - Masing-masing style dilengkapi preview gambar real — bukan cuma
       nama atau ikon.
     - Admin bisa upload gambar kustom untuk tiap style.

  c. Bahasa Indonesia Native
     - Seluruh UX, prompt AI, dan konten 100% Bahasa Indonesia.
     - Tidak perlu translate atau adaptasi dari tools luar negeri.

  d. Structured Workflow End-to-End
     - Panduan langkah demi langkah: Niche → Subniche → Topik → Tujuan →
       Audiens → Slide & Rasio → Gaya Visual → Generate AI → Edit Slide →
       Copy JSON.
     - Tidak ada blank canvas yang membingungkan — user diarahkan dari
       awal sampai selesai.

  e. Free Tier tanpa Kartu Kredit
     - 20 kali generate gratis.
     - Device-based blocking (1 perangkat = 1 akun free).

  f. Preset System
     - Simpan seluruh konfigurasi form sebagai preset.
     - Load kembali kapan saja — cocok untuk batch konten series.

  g. Slide Editor Interaktif
     - Tambah, hapus, dan reorder slide setelah AI generate.
     - Edit teks per slide secara manual.

  h. Admin Panel Lengkap
     - Manajemen user (role, tier, generate count).
     - Editor niche, subniche, visual categories, palettes.
     - Manajemen AI model & prompts.
     - Upload gambar style.
     - Custom categories — buat kategori visual sendiri.
     - Landing page CMS.

3. MENGAPA ORANG HARUS MENGGUNAKAN CAROFEED?
================================================================================

  a. Hemat Waktu
     - Dari 0 sampai JSON prompt siap pakai dalam 5-10 menit.
     - Tidak perlu mikir "slide 1 isi apa, slide 2 isi apa" — AI
       yang generate semua.

  b. Tidak Perlu Skill Design
     - Cukup isi form dan pilih style — output siap untuk image
       generator.
     - Tidak perlu Canva, Photoshop, atau skill desain grafis.

  c. Konten Lebih Terstruktur
     - Headline yang menarik, body yang informatif, visual idea yang
       sesuai — per slide.
     - Hasil lebih konsisten dibanding prompt ChatGPT manual.

  d. Bahasa Indonesia
     - Tidak perlu translate ide atau adaptasi konten.
     - AI memahami konteks dan budaya Indonesia.

  e. Cocok untuk Produksi Massal
     - Preset system memungkinkan produksi series konten dengan
       format konsisten.
     - Cukup ganti topik, generate, selesai.

  f. Gratis untuk Dicoba
     - 20 generate gratis, tanpa komitmen, tanpa kartu kredit.
     - Cukup login dengan akun Google — langsung bisa pakai.
     - Tidak perlu registrasi ribet: satu klik, langsung masuk.
     - Upgrade hanya jika sudah yakin.

6. SIAPA YANG TIDAK COCOK DENGAN CAROFEED?
================================================================================

  a. Yang Butuh Design Final Siap Posting
     - Carofeed output JSON prompt, BUKAN gambar jadi.
     - Masih perlu image generator (ChatGPT, Midjourney, dll) untuk
       render visual.

  b. Audiens Non-Indonesia
     - Seluruh UX, prompt AI, dan output dalam Bahasa Indonesia.
     - Tidak cocok untuk konten bahasa Inggris atau bahasa lain.

  c. Yang Ingin Generate Gambar Langsung
     - Carofeed fokus ke konten & prompt — bukan image generation.
     - Jika ingin satu platform dari awal sampai gambar jadi, carilah
       all-in-one design tool.

  d. Yang Prefer Full Manual Design Control
     - Jika ingin control pixel-level atas setiap elemen visual,
       Canva/Photoshop/Figma lebih cocok.
     - Carofeed mengotomatisasi, bukan memberikan kontrol manual
       detail.

  e. Enterprise dengan Compliance Ketat
     - Tidak ada opsi self-hosted.
     - Data tersimpan di Vercel KV (Upstash Redis) — tidak bisa
       on-premise.

  f. Yang Butuh Template Siap Pakai (Bukan Generate)
     - Carofeed AI-generated, bukan template library.
     - Jika ingin template carousel yang tinggal edit teks, Canva
       atau Slidesgo lebih cocok.
